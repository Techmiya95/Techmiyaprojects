Abstract: Parkinson's disease affects millions, and early detection is vital for managing symptoms. This project proposes a detection system that analyzes spiral and wave drawings (handwriting) or voice recordings to identify markers of Parkinson's using machine learning algorithms like SVM and XGBoost.

Introduction

Parkinson’s disease is a neurodegenerative disorder that impacts movement. The Parkinson’s Detector System leverages the subtle changes in motor skills that can be detected through hand-drawn patterns. By analyzing the speed, pressure, and deviation in drawings, the system can distinguish between healthy individuals and those with early-stage Parkinson's.

Professional Title

Early Diagnosis of Parkinson’s Disease using ML Algorithms on Motor Data

Advantages

  • Non-Invasive: Does not require complex medical procedures for initial screening.
  • Rapid Screening: Results can be processed in minutes.
  • Early Intervention: Enables patients to start therapy sooner, improving quality of life.
  • Objective Metrics: Provides measurable data points rather than subjective observation alone.

Disadvantages

  • Overlap with Other Tremores: Some symptoms may overlap with other conditions like essential tremor.
  • Requires Specialized Input: Needs digitized pens or high-resolution imaging for best results.
  • Not an Absolute Test: Must be combined with a full neurological clinical examination.

Conclusion

The Parkinson’s Detector System demonstrates how machine learning can assist in early medical screening. By focusing on easily observable motor patterns, it provides an accessible first step for diagnosis. Future projects could integrate video-based gait analysis for even broader detection capabilities.
