Abstract: This project develops an automated attendance system using facial recognition technology. By leveraging OpenCV and deep learning models, the system identifies individuals from a live camera feed and logs their attendance in a database, eliminating manual record-keeping and preventing proxy attendance.

Introduction

Traditional attendance systems using paper or ID cards are prone to errors and manipulation. The Face Recognition Attendance System offers a modern solution that is both secure and efficient. Using a camera-enabled device, the system captures faces, extracts unique features, and matches them against registered profiles to mark attendance in real-time.

Professional Title

Automated Time and Attendance Tracking using Deep Learning-based Facial Recognition

Advantages

  • High Accuracy: Minimizes human error in logging and reporting.
  • Touchless & Hygienic: Eliminates the need for physical contact with biometric devices.
  • Prevents Proxies: Ensures that only the authorized individual can mark their attendance.
  • Automated Reports: Generates daily, weekly, or monthly attendance reports instantly.

Disadvantages

  • Lighting Dependency: Performance can vary in low-light or fluctuating lighting conditions.
  • Hardware Requirements: Requires a decent quality camera and processing power for real-time analysis.
  • Privacy Concerns: Requires strict data security measures to protect facial biometric data.

Conclusion

The Face Recognition Attendance System is a powerful tool for organizations seeking to modernize their administrative tasks. It provides a seamless, secure, and transparent way to manage person-tracking. Future work could include multi-face recognition for large classrooms or integrating with existing HRMS software.
